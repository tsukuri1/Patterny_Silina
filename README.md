## О репозитории

В данном репозитории собраны отчёты и исходный код лабораторных работ по курсу «Паттерны проектирования». 

Каждая лабораторная работа посвящена изучению и практическому применению определённой группы паттернов проектирования (порождающих, структурных или поведенческих). В качестве прикладной задачи во всех работах выступает разработка приложения **«Траектория движения»** — расчёт параметров движения тела, брошенного под углом к горизонту. Это позволяет наглядно продемонстрировать, как одни и те же бизнес-требования решаются с помощью разных архитектурных подходов.

## Структура репозитория

Каждая лабораторная работа находится в отдельной папке и содержит:
- `README.md` — описание работы, цель, реализованные паттерны, структура приложения и скриншоты результатов.
- `main.py` — исходный код приложения (Python + Tkinter + Matplotlib).

## Как запустить любую из лабораторных работ

Для запуска приложений вам потребуется установленный Python 3 и библиотека `matplotlib`.

### 1. Клонируйте репозиторий

Откройте терминал и выполните команду:
git clone https://github.com/ВАШ_НИК/patterny.git
cd patterny

### 2. Создайте и активируйте виртуальное окружение

Это рекомендуется сделать, чтобы не устанавливать библиотеки глобально в систему:
python3 -m venv .venv
source .venv/bin/activate # Для macOS / Linux
.venv\Scripts\activate # Для Windows

После активации в начале строки терминала появится `(.venv)`.

### 3. Установите зависимости
pip install matplotlib

### 4. Запустите нужную лабораторную работу

Перейдите в папку нужной лабораторной работы и запустите скрипт:
cd lab01
python main.py
